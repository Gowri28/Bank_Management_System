# Bank Management System

## Project Description
This is a simple Bank Management System developed using Java. It allows users to manage bank accounts and perform basic banking operations.

## Functionalities
- Create Account  
- View Account Details  
- Deposit Money  
- Withdraw Money  
- Transfer Money  
- View Transaction History  

## Technologies Used
- Java  
- OOP (Object-Oriented Programming)  

## How to Run
- Open the project in Eclipse / VS Code  
- Run Main.java  
- Choose options from the menu  

## Classes Used
- Account – stores account details  
- BankService – handles operations  
- Transaction – stores transaction records  
- Main – user interface
